# Shared test vectors

JSON test vectors generated server-side by `liboqs-python` and consumed by the
TypeScript test suite, validating the `@noble/post-quantum` implementations of
ML-KEM-768 and ML-DSA-65 against an independent implementation (CLAUDE.md §3).

Populated in W3 alongside the handshake work. Files are committed so client CI
does not need liboqs.
